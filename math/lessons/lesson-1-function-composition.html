Targeted Lesson 1

Function Composition & Hidden Parameters

WHEN I SEE an unknown linear function composed with itself → I write f(x) = ax + b immediately.

Recognition cue: If f is linear but its formula is unknown, create the general form yourself.

Worked pattern

Suppose f(f(x))=9x+8. Write f(x)=ax+b. Then f(f(x))=a²x+b(a+1). Match coefficients. The key move is creating the unknown linear function before trying to solve.

Algebra or Desmos?

Usually algebra first. Desmos helps only after translating the composition into equations.

Common trap

Treating f(f(x)) as f(x)².

Transfer practice

1. A linear function g has g(g(x))=16x+15. If g has positive slope, what is g(0)?
2. A linear function h has h(h(x))=25x-18 and positive slope. What is h(0)?
3. A linear function p has p(p(x))=4x+9 and positive slope. What is p(5)?
