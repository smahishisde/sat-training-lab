Targeted Lesson 1 — Function Composition & Hidden Parameters

WHEN I SEE an unknown linear function composed with itself → write f(x)=ax+b immediately.

Take your time here. The goal is to understand the pattern well enough that a different-looking SAT question still feels familiar.

See the structure first

Worked example — teacher walkthrough

First: why this feels confusing

The SAT gives you f(f(x)) but does not tell you the formula for f. That can make it feel like there is nothing to work with. But the word linear is enough. Every linear function has the form f(x)=ax+b. So our first job is not to solve anything—it is to name the unknown function.

What composition actually means

f(f(x)) means: do f once, then take that output and use it as the next input. If f(x)=ax+b, the first output is ax+b. The second f now receives ax+b instead of x.

Make the substitution slowly

Start with the template f(input)=a(input)+b. The new input is ax+b. So f(f(x))=a(ax+b)+b. This is the single most important step.

Now simplify

a(ax+b)+b = a²x+ab+b = a²x+b(a+1). Now the expression has an x-part and a constant part.

Match what the SAT gives you

If the problem says f(f(x))=9x+8, then the x-coefficient must be 9, so a²=9. Therefore a=3 or -3. If the problem says positive slope, choose a=3.

Finish the constant

With a=3, b(a+1)=8 becomes 4b=8, so b=2. Therefore f(x)=3x+2.

Why this is actually a pattern-recognition problem

The underlying math is basic linear algebra. The hard part is noticing that 'linear but unknown' means you are supposed to invent f(x)=ax+b.

What to write first on test day: Write this immediately: f(x)=ax+b

Common wrong turn

Do not turn f(f(x)) into [f(x)]². Composition is substitution, not multiplication or squaring.

Guided example

A linear function g has positive slope and g(g(x))=16x+10. What is g(0)?

Let g(x)=ax+b. From a²=16 and positive slope, a=4. Then b(5)=10.
