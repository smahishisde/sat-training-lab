Targeted Lesson 1

Function Composition & Hidden Parameters

WHEN I SEE an unknown linear function composed with itself → I write f(x) = ax + b immediately.

Recognition cue: If the function is declared linear, its unknown formula is not a dead end. Create the general linear form and compose it.

Worked pattern

If f(f(x))=9x+8 and f(x)=ax+b, then f(f(x))=a²x+b(a+1). Match coefficients. If the slope sign is specified, it selects the correct value of a.

Algebra or Desmos?

Algebra first. Desmos can check the resulting equations, but it should not replace the structural setup.

Common trap

Treating f(f(x)) as [f(x)]² or guessing a formula.

5-question transfer check

Near transfer
1. A linear function g has g(g(x))=16x+15. If g has positive slope, what is g(0)?
Different presentation
2. A linear function h has positive slope. h(h(x))=25x-18. What is the y-intercept of h?
SAT-style trap
3. A linear function p has p(p(x))=4x+9 and positive slope. What is p(5)?
Strategy choice
4. A linear function r has negative slope and r(r(x))=9x+8. What is r(0)?
Far transfer
5. A linear function t has positive slope and t(t(x))=36x+35. What is t(0)?
