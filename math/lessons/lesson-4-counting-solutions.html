Targeted Lesson 4

Counting Solutions & Intersections

WHEN I SEE 'how many solutions' with an absolute value or parameter → think intersections before solving individual equations.

Let’s learn this like a tutor would teach it

This kind of problem looks like algebra, but the easiest way to understand it is often visually.

When the SAT asks 'how many solutions,' you usually do not need the actual x-values. You need to know how many times two graphs meet.

Worked example — talk it through with me

Translate the equation into two graphs

Take |x²-9|=k. Think of this as y=|x²-9| and y=k.

Understand the first graph

y=x²-9 is a parabola shifted down 9 units.

Now apply absolute value

Any part of that parabola below the x-axis flips upward. That creates a W-like graph.

Understand k

y=k is just a horizontal line whose height depends on k.

Count intersections instead of solving

For a positive k smaller than 9, the horizontal line cuts the W-shaped graph four times, so there are four solutions.

Find the special height

At k=9, the two inner intersections come together at x=0.

Count again

Now there are only three distinct x-values where the graphs meet. So k=9 gives exactly three real solutions.

Desmos decision

This is an excellent Desmos problem. Graph y=abs(x²-9), graph y=k, and move k. You are looking for the moment the number of intersections changes.

What I want you to remember: Number of solutions = number of intersections. If a parameter is acting like a horizontal line, count visually before doing branch algebra.

Common wrong turn

Do not count algebra branches. Two branches can produce the same x-value. The SAT asks for distinct solutions.

Try one with me

Guided check: For what positive k does |x²-25|=k have exactly 3 distinct real solutions?

If this still feels unclear, go back to the worked example before continuing.

5-question transfer check

Now prove you can recognize the same idea when the SAT changes the presentation.

Near transfer

Different presentation

SAT-style trap

Strategy choice
