Math Module 2 Playbook

A cumulative set of recognition cues, shortcuts, and strategy decisions.

This page contains distilled tactics only—no scores, question history, or personal information.
PatternWHEN I SEE THISI DO THISShortcut / tactic
Function compositionUnknown linear function composed with itselfWrite f(x)=ax+b, compose, then match coefficients.Algebra first.
Coordinate-circle modelingCircle tangent to both coordinate axesCenter is (r,r); write the point-to-center distance equation.Use Vieta if only sum/product of radii is needed.
Right-triangle altitudeAltitude drawn from the right angle to hypotenuseExpect three similar triangles; use geometric-mean relationships.Do not stop at the altitude if a different quantity is asked.
Counting solutionsParameter + absolute value / nonlinear equationThink graph intersections and special heights before branch-solving.Desmos is often advantageous.
Horizontal transformationsf(x+c) or f(x-c)Inside shifts run opposite the sign: +c left, -c right.Substitute carefully before visualizing.
Negative substitutionPolynomial evaluated at a negative numberPut the entire negative input in parentheses before simplifying.Do a final sign check.
Desmos triageUgly nonlinear equations / intersection countingAsk whether graphing turns the problem into reading intersections.Use Desmos when representation is the hard part, not by habit.
Structure before grindLong algebraic expressionsLook for substitution, factoring, symmetry, identities, or a requested aggregate.Do not solve for more variables than the question asks for.
